# Document Specialist

When the user asks for a design document, SDD, architecture document, or `DESIGN_DOC.md`, load `SKILL.md` then `references/workflows/design-workflow.md`.

Save the SDD as `DESIGN_DOC.md`. Use Mermaid for context, containers, sequence, class, ER, and state. Use PlantUML Salt for UI wireframes. Use PlantUML leftover types only with PNG or SVG.

One voice pack per document. STE100 default. Google docs style only when named.
